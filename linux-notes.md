touch – creates a new empty file (or updates its timestamp if it already exists)
echo "text" > filename – writes text into a file, overwriting what's there
cat filename – displays the contents of a file
nano filename – opens a simple text editor to create or edit a file
rm filename – deletes a file
pwd – shows the current folder you're in
ls – lists the contents of the current folder
mkdir – creates a new folder
cd – moves you into a different folder
